# SEDUC Especialistas

Sistema de Atendimento Especializado da Rede Municipal de Ensino de Frei Inocêncio/MG.

Aplicação implementada com Firebase Hosting, Authentication Google e Firestore Standard. A implantação padrão não usa Cloud Functions e mantém o projeto no plano gratuito.

Inclui escolas, profissionais, vínculos e jornadas, alunos e matrículas, agenda, atendimentos, frequência funcional, encaminhamentos, relatórios agregados CSV/PDF, aprovação de usuários, auditoria e consulta de servidores escolares. Autenticação, permissões e banco são independentes do SISDIFI.

Consulte a [especificação funcional](docs/ESPECIFICACAO.md) e o [guia operacional](docs/OPERACAO.md) para desenvolvimento, publicação, segurança e consumo de leituras.

> **Privacidade:** este repositório é público apenas para código e documentação. Os dados de alunos, menores de idade, famílias, profissionais e atendimentos não podem ser armazenados aqui nem ficar acessíveis sem autenticação e autorização.
